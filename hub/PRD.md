# PRD — 이음:교재 (성경 이야기 시뮬레이션 512편)

## 1. 한 줄 요약
성경 66권 512편의 이야기 시뮬레이션 교재를 이음허브 안에서 찾아보고, 열어 보고, 교회학교 수업에 배정할 수 있게 한다.

## 2. 배경
- 원장님이 만든 성경 이야기 교재 HTML 512편(1편당 약 100KB, 총 약 49MB)이 있다.
- 각 파일은 혼자서 완전히 작동하는 단일 HTML이다. 외부 의존성은 구글 폰트뿐이다.
- #1–299는 v1 스타일, #300–512는 v2 시네마틱 스타일이다. **#1–299는 앞으로 순차 리메이크 예정**이라 파일이 계속 바뀐다.
- 그래서 교재 파일은 이음허브 본체와 **분리된 정적 사이트(bible-sim)** 에 두고, 허브는 목록과 화면만 담당한다.

## 3. 구조
```
[bible-sim 정적 사이트 · Vercel]            [이음허브 · Next.js 14 + Supabase]
  /s/001 … /s/512  (교재 원본)  ←iframe─  /edu/bible          목록·검색·필터
  /view?n=94   (이전/다음 보기 화면)       ←iframe─  /edu/bible/[no]     교재 보기
  /catalog.json (512편 목록)               ─seed→    edu.bible_simulations (Supabase 표)
```
- 교재 원본 수정(리메이크)은 bible-sim 저장소에 push만 하면 자동 재배포된다. 허브는 배포하지 않아도 된다.
- 목록 데이터는 Supabase에 둔다. 그래야 허브의 권한 체계, 수업 배정, 학습 기록과 연결된다.

## 4. 사용자와 권한
| 역할 | 할 수 있는 일 |
|---|---|
| 로그인한 모든 성도 | 목록 보기, 교재 열기 |
| 교사(교회학교 사역 역할) | 반에 교재 배정, 반 학생 학습 기록 보기 |
| 관리자 | 목록 데이터 수정(스타일 v1→v2 표시 등) |

## 5. 기능 (MVP → 2단계)
### MVP (1단계)
1. **목록 화면** `/edu/bible`
   - 검색: 번호(예: 94), 제목, 인물, 성경책
   - 필터: 구약/신약, 성경책(66권 순서), 주제, 대상(어린이/청소년/성인)
   - 정렬: 번호 순 / 성경 순서(책별 묶음)
   - 카드: 번호·구약/신약·성경책·참조 구절·제목·요약 2줄
2. **교재 보기** `/edu/bible/[no]`
   - 상단: 번호·제목·참조 구절, 이전/다음, 목록으로
   - 본문: `iframe src = {BIBLE_SIM_URL}/s/{NNN}`
   - 아래 접이식 패널: 요약, 의미, 나눔 질문 (DB 값)
3. 이음허브 메뉴에 "성경 이야기 교재" 추가

### 2단계
4. **수업 배정** — 교사가 반(순/부서)에 "이번 주 교재"를 지정한다. 학생 홈에 카드로 노출된다.
5. **학습 기록** — 교재를 연 시각을 기록하고, 교사가 반별 진행률을 확인한다.
6. **리메이크 현황** — style 컬럼(v1/v2)으로 리메이크 진행률을 관리자 화면에 표시한다.

## 6. 성공 기준
- 목록 첫 화면이 1초 안에 뜨고, 512편 검색·필터가 즉시 반응한다.
- 휴대폰(360px)에서 가로 스크롤 없이 목록과 교재가 보인다.
- 교재 리메이크 후 허브를 재배포하지 않아도 새 교재가 보인다.

## 7. 범위 밖
- 교재 HTML 자체의 수정 (별도 프로젝트: 성경 이야기 시뮬레이션 교재)
- 교재 원본을 Supabase Storage에 올리는 방식 (HTML이 text/plain으로 내려와 iframe 표시가 번거롭다)
