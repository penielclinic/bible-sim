# bible-sim — 성경 이야기 교재 512편

교회학교용 성경 이야기 시뮬레이션 512편을 담은 정적 사이트. 이음허브에서 iframe으로 불러와 사용한다.

- `/` 목록 (검색·구약/신약·성경책·주제·대상 필터) — `?embed=1` 붙이면 머리글 숨김
- `/view?n=94` 교재 보기 (이전/다음 이동) — `&nav=0` 붙이면 상단 막대 숨김
- `/s/094.html` 교재 원본 파일 (단독 실행)
- `/catalog.json` 512편 목록 데이터
- `hub/` 이음허브 연동 문서·시드 SQL (배포 제외, .vercelignore)

리메이크한 교재는 `s/NNN.html`을 같은 번호로 교체 후 push → Vercel 자동 재배포.
